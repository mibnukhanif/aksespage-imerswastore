Wajib Ubah URL App Script di Frontend!

Agar aplikasi bisa terhubung ke database Google Sheets Anda sendiri, Anda WAJIB mencari baris kode berikut di setiap file HTML dan menggantinya dengan URL Web App Google Apps Script Anda yang sudah di-deploy:

const SCRIPT_URL = 'URL WEB APP GOOGLE APPS SCRIPT ANDA MASUKAN DISINI';

Lokasi file yang harus diedit:

  • dashboard.html — ada di baris : 90
  • index.html — ada di baris : 483
  • login.html — ada di baris : 96
  • artikel.html — ada di baris : 154

Panduan Desain iMersWAstore

Rekomendasi Ukuran Gambar:

Banner Toko

  • Dimensi: 800 x 300 px (atau 1200 x 400 px untuk HD).
  • Format Rasio: Sekitar 21:9 atau 8:3 (Memanjang / Landscape).
  • Tips Penting: Pastikan teks, logo, atau objek utama diletakkan persis di tengah gambar. Hindari meletakkan teks penting terlalu mepet ke ujung atas, bawah, kanan, atau kiri agar tidak terpotong saat dibuka di ukuran layar HP yang berbeda-beda.

Gambar Produk

  • Format Rasio: Ukuran Square 1:1 (Kotak Sempurna).
  • Dimensi Ideal: 500 x 500 px atau 800 x 800 px.
  • Keuntungan: Ukuran ini membuat gambar produk tetap tajam dan tidak pecah saat di-zoom atau dibuka di modal detail produk.
